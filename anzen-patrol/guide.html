安全パトロールアプリ　かんたん登録ガイド

スマホ・タブレットの画面に、1タップで開けるアイコンを追加する手順です

毎回URLを入力してブラウザを開く必要はありません。下の手順で端末のホーム画面(またはスタート画面)にアイコンを追加すると、次回からアイコンをタップするだけで「安全パトロール」がすぐに開きます。サインインは不要です。

まずはカメラでQRコードを読み取ってください

iPhone・iPadは「カメラ」アプリでQRコードを読み取り、通知をタップすると Safari で開きます。Windowsタブレットは、カメラアプリまたは Microsoft Edge のQRコード読み取り機能をご利用ください。

Windows タブレット
Microsoft Edge でページを開いた状態から始めます
  1. QRコードを読み取るか、URLを入力して Microsoft Edge でこのページを開きます。
  2. 画面右上の「…」(設定など)ボタンをタップします。
  3. 「その他のツール」→「アプリ」と進みます。
  4. 「このサイトをアプリとしてインストールします」をタップします。
  5. 確認画面で「インストール」をタップすると、専用ウィンドウで開きます。
  6. 開いたウィンドウの「…」ボタンから「その他のツール」→「スタートにピン留めする」(または「タスク バーにピン留めする」)を選ぶと、次回から1タップで起動できます。
iPad・iPhone
Safari でページを開いた状態から始めます
  1. QRコードを読み取るか、URLを入力して Safari でこのページを開きます。
  2. 画面上部(またはアドレスバー付近)の共有ボタン(四角に上向き矢印のアイコン)をタップします。
  3. 一覧から「ホーム画面に追加」を選びます。見当たらない場合は一覧を下にスクロールしてください。
  4. 表示名を確認します(そのままで問題ありません)。
  5. 右上の「追加」をタップすると、ホーム画面にアイコンが追加されます。
  6. 次回からはそのアイコンをタップするだけで、安全パトロールの画面がすぐに開きます。
Windows PC
Edge / Chrome でページを開いた状態から始めます
  1. QRコードをスマホで読み取るか、URLをアドレスバーに直接入力してこのページを開きます。
  2. ページが開いたら Ctrl + D でお気に入りに追加します。
  3. 次回からはお気に入りバーのアイコンをクリックするだけで開けます。
基本の使い方
アプリを開いたあとの流れ
  1. 「新規記入」タブでチェック項目・評価を入力します。
  2. 入力が終わったら「提出する」を押します。
  3. 「記録一覧・管理」タブで、過去の記録の確認・編集・印刷ができます。
うまくいかないときは
  • Edgeに「アプリ」の項目が見当たらない場合は、Edge を最新版に更新してからお試しください。
  • iPad・iPhoneで「ホーム画面に追加」が見当たらない場合は、共有シートを下までスクロールしてください。
  • 追加後に画面が真っ白になった場合は、アイコンを削除して手順をやり直してください(記録データは消えません)。
